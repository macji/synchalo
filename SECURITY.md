# Security Policy

## Supported versions

Only the latest published SyncHalo version receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
**Security → Advisories → Report a vulnerability** flow at
<https://github.com/macji/synchalo/security/advisories/new>.

Include the affected version, platform, impact, and minimal reproduction. Do
not include real clipboard contents, private keys, pairing codes, or unrelated
personal files. Maintainers will acknowledge a report as soon as practical,
coordinate a fix and disclosure, and revoke affected release artifacts or
signing credentials when required.

Official releases are published only at
<https://github.com/macji/synchalo/releases>. Windows installers are signed by
SignPath Foundation, macOS applications are signed with the project's Apple
Developer ID and notarized by Apple, and Ubuntu APT metadata is signed by the
SyncHalo archive key.
